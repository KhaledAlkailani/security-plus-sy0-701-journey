# Exam Integrity

This repository contains original Security+ SY0-701 study notes, comparisons, and scenarios.

It intentionally excludes:

- leaked exam questions;
- proprietary exam dumps;
- memorized live-exam questions;
- unauthorized answer keys.

The purpose is to document cybersecurity learning and reasoning, not to reproduce protected exam content.

Official CompTIA objectives should remain the source of truth for the exam scope.

# IAM vs PAM

## IAM — Identity and Access Management

IAM manages the broader identity lifecycle:

- user creation;
- authentication;
- access assignment;
- roles;
- MFA;
- provisioning;
- deprovisioning.

## PAM — Privileged Access Management

PAM focuses on high-risk privileged access:

- administrator accounts;
- privileged credentials;
- session control;
- credential vaulting;
- just-in-time privilege;
- privileged activity monitoring.

## Simple distinction

```text
IAM = access management for identities broadly
PAM = tighter control of privileged access
```

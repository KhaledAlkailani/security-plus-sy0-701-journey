# Quick Recall

## Identity

```text
Authentication = Who are you?
Authorization  = What can you do?
IAM            = broad identity/access lifecycle
PAM            = privileged access
```

## Controls

```text
Preventive = stop
Detective  = discover
Corrective = restore / fix
```

## Crypto

```text
Hashing    = one-way
Encryption = reversible with key
Signature  = integrity + authenticity + non-repudiation
```

## Network

```text
IDS = detect
IPS = detect + block

Stateless = packet-by-packet
Stateful  = connection-aware
```

## Vulnerability Management

```text
Scan → Validate → Prioritize → Remediate → Verify
```

## Incident Response

```text
Prepare → Detect/Analyze → Contain → Eradicate → Recover → Learn
```
